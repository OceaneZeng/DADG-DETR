原高学习率 control 在没有图/发现模块时也会失去像素响应；仅缩小学习率的新 control
现在稳定到第 8 轮。因此，当前 batch 与初始化下的基础优化步长是已获得强证据支持的
重要因素，不能再把此前所有低 AP 全部归给 GNN 或伪未知监督。
仍未证明学习率是所有版本的唯一根因、5e-5 最优，或 v8 排序目标及候选污染问题已解决。
原高学习率 control 只有 3 轮记录，没有其第 8 轮配对结果；不能虚构同轮直接对比。
